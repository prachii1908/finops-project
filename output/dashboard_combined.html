📥 Monthly update — 5 minutes, first-of-every-month

1
Azure Portal → Cost Management + Billing → Cost analysis → set scope to your subscription
2
Export 1 (Monthly RG): Group by = ResourceGroupName · Granularity = Monthly · full month date range → Download → Excel (.xlsx)
3
Export 2 (Daily RG): Same but Granularity = Daily → Download → Excel
4
Export 3 (Resources): Switch view to "Resources" · same date range → Download → Excel
5
Drop all 3 files into the exports/ folder (any filename — auto-detected)
6
Run: python process_costs.py
7
Open the new file in output/ — share it by email, Teams, or SharePoint

🌐 Option A · Vercel (Recommended — free, permanent URL)

1
Go to vercel.com → Sign Up free (use your email or GitHub)
2
Click Add New → Project → drag and drop your output/ folder into the upload area
3
Vercel detects index.html automatically → click Deploy
4
Your permanent URL is ready: https://your-project.vercel.app — share this with clients and managers
5
Every month: run script → go to Vercel → your project → Deployments → Upload → drop new output/ folder → URL stays the same

🐙 Option B · GitHub Pages (free with public repo)

1
Create a free account at github.com → New repository → name it finops-dashboard
2
Upload index.html from your output/ folder to the repo root (drag and drop on the web UI)
3
Go to Settings → Pages → Branch: main → Save
4
URL is live at: https://yourusername.github.io/finops-dashboard/
5
Every month: run script → upload new index.html → click Commit → URL auto-updates in ~1 minute
⚠
Free GitHub Pages requires a public repository. If cost data is sensitive, use Vercel instead (URL is not guessable).
